# 🌡️ Temperature Converter Web Application

📌 **Task 01 – SkillCraft Technology Internship**

This project is Task 01 of my SkillCraft Technology Internship. It is a modern, responsive Temperature Converter Web Application built using pure HTML5, CSS3, and JavaScript (ES6). The application performs real-time temperature conversions between Celsius (°C), Fahrenheit (°F), and Kelvin (K) through a clean and intuitive user interface.

---

### ✨ Features
* Convert seamlessly between Celsius, Fahrenheit, and Kelvin scales
* Instant real-time conversion dynamic updates
* Modern responsive user interface with clean design
* Smooth animations and interactive input handling
* Strict input validation for edge cases and numerical limits
* Lightweight, standalone web app with zero dependencies

---

### 🛠️ Technologies Used
* **HTML5:** Semantic markup and structure
* **CSS3:** Custom layout styling, responsiveness, and animations
* **JavaScript (ES6):** Conversion algorithms and DOM manipulation
