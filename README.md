🌡️ Temperature Converter Desktop App

🖥️ Task 1 – SkillCraft Technology Internship

A modern Temperature Converter Desktop Application built using HTML, CSS, JavaScript, and Electron.js.

The application allows users to perform real-time temperature conversions between Celsius (°C), Fahrenheit (°F), and Kelvin (K) through a clean, interactive, and modern desktop interface.

🔥 Features

🔄 Convert between Celsius, Fahrenheit, and Kelvin

⚡ Instant real-time conversion

🪟 Desktop application powered by Electron.js

🎨 Modern Glassmorphism user interface

✨ Smooth animations and hover effects

📱 Responsive interface

🛡️ Input validation

🚀 Lightweight and easy to use

🧰 Technologies Used

🌐 HTML5

🎨 CSS3

⚙️ JavaScript (ES6)

🖥️ Electron.js
